# 🏪 All-in-One Dewangan Shop Manager

A cloud-based shop management application built using Python, Streamlit, and Supabase. It helps manage products, shopping lists, and purchase history for multiple shop categories in one place.

## 📌 Project Overview

The All-in-One Dewangan Shop Manager is designed to simplify the management of a family business that includes grocery, hardware, stationery, and electronics.

Family members can add items to a shared shopping list, set priorities, update item status, and track purchase history. This makes it easier to organize requirements and manage purchases efficiently.

## ✨ Features

- 🔐 Password-protected access
- 📊 Dashboard with shopping statistics
- 🛒 Separate categories for Grocery, Hardware, Stationery, and Electronics
- ➕ Add new items to the shopping list
- ✏️ Edit and delete items
- 🚦 Set item priorities: High, Medium, and Low
- ✅ Mark items as Purchased or Pending
- 📝 Add notes to shopping items
- 📅 Track item creation and purchase dates
- 📜 View shopping history
- 📥 Export shopping data as a CSV file
- ☁️ Cloud database using Supabase

## 🛠️ Technologies Used

- **Python** — Application logic
- **Streamlit** — User interface
- **Supabase** — Cloud database
- **Git & GitHub** — Version control and project hosting
- **Streamlit Community Cloud** — Application deployment
